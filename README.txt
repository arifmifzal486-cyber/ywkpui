CARA MENAMBAHKAN FOTO SENDIRI
==============================
Taruh file foto kamu di dalam folder "images" ini dengan nama PERSIS seperti di bawah.
Begitu file dengan nama yang sesuai ada di folder ini, foto akan otomatis muncul di website
menggantikan kotak placeholder abu-abu — tidak perlu edit kode HTML/CSS/JS sama sekali.

Format: .jpg (bisa juga .png/.jpeg, tapi ganti juga ekstensinya di file index.html & script.js
jika tidak pakai .jpg)

CATATAN
- Selama foto belum ada, website akan menampilkan kotak placeholder abu-abu bertuliskan
  nama & lokasi file yang dibutuhkan — jadi kamu tahu persis foto mana yang harus ditaruh di mana.
- Ukuran foto disarankan minimal 1200px di sisi terpanjang agar tetap tajam.
- Pastikan folder "images" ini sejajar (satu level) dengan index.html.
